## Exam format

| | |
|---|---|
| Scored questions | 50 |
| Unscored questions | 15 (not identified during the exam) |
| Scaled score range | 100–1,000 |
| **Passing score** | **700** |
| Scoring model | Compensatory — you don't need to pass each section individually |
| Question types | Multiple choice, multiple response, ordering, matching |

Unanswered questions score as incorrect, and there is no penalty for guessing — so never leave one blank.
